# 🌶️ Spicy Discount Searcher

A Chrome/Brave extension that takes a spreadsheet full of corporate discount
codes, races them against each other on the rental car and hotel sites, and
tells you which one is actually cheapest for your trip.

You give it a pick-up airport and some dates. It opens each vendor's own search
with a different corporate code applied, reads the prices off the results page,
and ranks them.

URLs, so the query parameters in `src/core/deeplinks.ts` are reverse-engineered

a results page, that's the one file to fix — see
[Fixing a deep link](#fixing-a-deep-link).

## Install (Brave or Chrome)

```bash
npm install
npm run build
```

Then load it:

1. Open `brave://extensions` (or `chrome://extensions`).
2. Turn on **Developer mode**.
3. **Load unpacked** → select the `dist/` folder.
4. Pin 🌶️ Spicy Discount Searcher to the toolbar.

Rebuild after any source change and hit **Reload** on the extension card.

## How a search runs

1. You pick a category (cars or hotels), a trip, which vendors to try, and
   which companies' codes to race.
2. The popup expands that into candidates — one per distinct vendor + code
   pair. Codes listed under two companies collapse into one candidate, and an
   Enterprise contract id is also tried at National.
3. The background service worker opens a **minimised** window and loads a few
   candidates at a time (default 2, 750 ms apart) so your browsing isn't
   hijacked and no vendor gets hammered.
4. A content script on each page polls until the prices stop changing, then
   reports every offer it found.
5. The tab closes, results stream back into the popup ranked cheapest first,
   with the spread between best and worst.

Closing the popup doesn't stop a run — state lives in the service worker and
`chrome.storage.session`, so reopening picks the results back up.

### Comparing fairly

Two guards keep the ranking honest:

- **Price basis.** Every scraped number is tagged `total`, `per-day`, or
  `unknown`, and only like beats like. A `$29/day` badge can never appear to
  undercut a rival's real `$210` trip total.
- **Class matrix.** If the winning code is only cheap because it surfaced a
  different car class than everyone else, the popup says so instead of
  pretending it won.

## The code database

`src/data/codes.generated.json` is **generated** from
`data/source/Hotel & Car Rental Corporate Codes.xlsx`. Don't hand-edit it.

```bash
npm run codes    # or: ./scripts/extract_codes.py
```

The workbook is a human spreadsheet, so the parser has to deal with several
codes per cell (`A541100 or A541105`), Excel turning `260290` into `260290.0`,
booking URLs sitting where a code should be, and parenthetical asides. It also
refuses to read letter-only "codes" out of prose-heavy cells, which is what
stops `Hampton Inn` from becoming a code called `INN`.

CI regenerates the JSON and fails if it differs from what's committed, so the
data and the workbook can't drift apart.

Swapping the workbook for a live source later means replacing that one script
and keeping the JSON shape — nothing else knows where the codes came from.

## Fixing a deep link

When a vendor's search doesn't pre-fill:

1. Go to the vendor's site and run the search by hand, with the code applied.
2. Copy the URL from the address bar.
3. Update that vendor's builder in `src/core/deeplinks.ts` to match.
4. Flip its `confidence` from `'best-effort'` to `'verified'`.
5. Update the matching case in `tests/deeplinks.test.ts`.

Price extraction is the same idea in `src/core/extract.ts`: `VENDOR_SELECTORS`
holds per-vendor CSS, and a generic currency sweep runs when the selectors miss,
so a vendor redesign degrades instead of breaking.

## Layout

```
src/
  core/            pure logic, all unit-tested
    types.ts       shared shapes
    vendors.ts     vendor registry — host permissions derive from this
    codes.ts       load/query the database, expand a selection into candidates
    deeplinks.ts   per-vendor search URLs  ← the fragile part
    extract.ts     read prices off a results page
    compare.ts     ranking, savings, class matrix
    messages.ts    popup ↔ background ↔ content protocol
  background/      service worker: queue, tab pool, aggregation
  content/         injected probe, inert unless a run is active
  popup/           UI
  data/            generated code database
scripts/
  extract_codes.py workbook → JSON
  make_icons.py    generates the PNG icons
  check-dist.mjs   CI guard that dist/ is loadable
```

npm run build        # typecheck + both vite builds

CI runs build/typecheck/lint, tests, the data-freshness check, and a gitleaks
secret scan on every PR. `main` is protected — all four must pass, and the
branch must be up to date before merge.

## A note on the codes

These are negotiated corporate rates that belong to the companies that
negotiated them. Most are widely circulated, but a rate you aren't entitled to
can be refused at the counter or on check-in, sometimes after the reservation
looks confirmed — some vendors ask for a corporate ID or badge. Treat what this
tool finds as a shortlist to verify, not a booked price. Nothing here
circumvents a vendor's authentication or eligibility checks; it just fills in
codes you already have on their own public search forms.
